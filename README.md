# Pérez Viera Asesores · propuesta de sitio web

Maqueta de la nueva web de Pérez Viera Asesores de Seguros (Cali, desde 2015). Es una propuesta de diseño, todavía no
es el sitio oficial.

## Páginas

- `index.html`: inicio.
- Una página por seguro: vida, salud, autos, hogar y empresas.
- Contacto, preguntas frecuentes, nosotros y políticas.

## Verla

- **En local:** doble clic en `index.html`. Necesita internet para las letras.
- **En Vercel:** importar el repositorio con el preset «Other». No hace falta comando de build ni carpeta de salida.

Las fotos y el vídeo son ilustrativos, hechos con IA, y así lo indica cada uno. Los textos salen de perezvierasesores.com.
